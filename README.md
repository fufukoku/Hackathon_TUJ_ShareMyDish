# Hackathon_TUJ_ShareMyDish
A web app that lets people share leftover food with neighbors to reduce waste and build community.

## How it works 
The user can choose one of the two modes: upload mode and search mode. 
In upload mode, the user is able to upload the following:
- location of food 
- image of the food
- type of the food (for example, ramen, sandwich, bread, etc.)
- date creation of the food
- date expiration of the food
Once the user is done filling this information out, they see a special code which they note down for when people wish to get the food they listed. 

In search mode, the user is able to see all the available food items on the map. If they wish to get the food item, they will need to chat with the user who created the food listing and get the special code which they will input to get the food item.
